定期演奏会の趣旨と関係者の役割

趣旨

定期演奏会は、吹奏楽部が1年間の活動の成果を発表し、日頃お世話になっている地域・協賛企業・保護者へ感謝を伝える場です。同日には「3年生を送る会」も行い、後輩たちが3年間の活動に感謝を伝えます。

  • 生徒にとって：日頃の練習の集大成を発表し、達成感・自信を得る機会
  • 地域にとって：地域に愛される学校・部活動として交流を深める機会
  • 保護者会にとって：協賛広告・寄付を通じて部活動運営資金を確保する、年間最大の事業

学年ごとの意義

  • 1年生：入部から1年間の成長を最も感じられる機会
  • 2年生：イベントの中心となりリーダーシップを発揮する機会
  • 3年生：部活動最後の締めくくりとなる一大イベント

もう一つの趣旨：楽器購入費の創出。協賛金・寄付金による収益は、老朽化した楽器の買い替え費用にも充てられています。前例では、ある年度の楽器購入費が約180万円（フルート、ユーフォニアム、ホルン、トロンボーン、クラリネット、譜面台等）にのぼりました。「発表の場」であると同時に「部活動を維持するための資金事業」でもあることを共有しておくと、協賛依頼への納得感が高まります。

関係者と役割

この行事は、生徒・顧問の先生・保護者全体・地域の協賛企業/寄付者など、多くの関係者の協力によって成り立っています。

保護者会役員会（事務局）
  • 全体の進行管理（スケジュール、予算、協賛金の管理）
  • 顧問の先生・生徒・保護者全体・外部業者（印刷、DVD等）・協賛企業との連絡調整
  • 保護者説明会や当日運営に必要な準備の統括、役割分担の決定
  • 保護者会会則に基づく正式な組織（会長・副会長・書記・会計・監事）で構成
保護者会（保護者全体）
  • 協賛広告の訪問依頼、生徒送迎、当日の手伝い（受付・駐車場案内等）への協力
  • 保護者会費の納入
  • 役員会からの連絡・呼びかけへの対応
顧問の先生
  • 演奏内容、練習・タイムスケジュールなど部活動運営の中心を担う
  • 学校施設（公民館予約含む）や生徒指導に関する窓口
  • パンフレットの挨拶文、当日の進行内容等について役員会と調整
生徒
  • 演奏・発表そのものの主役
  • 楽器運搬、会場設営、募金活動、展示物制作など、できることは生徒自身が行う
  • 3年生を送る会では、後輩から感謝を伝えられる立場になる
協賛企業・寄付者
  • 地域の企業・店舗・個人等、広告掲載や寄付金という形で活動を支援
  • パンフレット配布や当日案内を通じて、活動報告・感謝を伝える対象
  • 翌年度以降も継続してご協力いただけるよう、丁寧な依頼・お礼・領収書発行を行う

資金調達の仕組み（誰が何をするか）

定期演奏会の運営費は、次の流れで集まります。

  1. 役員会（事務局）が保護者会全体に「協賛金・寄付金を集めてほしい」と呼びかける
  2. 各保護者が、自分の知り合いの企業・お店・個人などへ個別に訪問・依頼する
  3. 引き受けてもらえたら、まず依頼した保護者（担当者）が協賛金・寄付金を受け取る
  4. 担当保護者が役員会（会計）へ協賛金を引き渡し、役員会が集約・入金する

「役員会 → 保護者会全体 → 企業・個人（協賛企業・寄付者）→ 担当保護者 → 役員会」という一つの輪になっています。

進捗は「広告協賛リスト」で事業者ごとに次のステータスを管理します。

アクション中（企業側へ確認中）→ 確約 → 担当者が協賛金受領 → 役員会が協賛金受領 → 広告デザイン決定済 → 完了（役員受領＆デザイン確定済）

広告協賛リストの主な管理項目：学年／担当保護者名／事業者名／ステータス／広告サイズ／今年度の広告料金／役員会協賛金受領金額／デザイン渡し方法／備考

段階ごとの準備内容（フェーズA〜J）

A
会場予約・準備開始時期：8月

やること

  • 定期演奏会の開催日（予備日含む）を確認する
  • 豊見城市中央公民館の予約手続きを進める

誰に確認するか

  • 顧問 → 開催希望日、会場予約の可否

提出書類

  • 公民館使用許可申請書、駐車場（公園）使用許可申請書 等

生涯学習振興課から毎年11月に学校へ届く「次年度公民館利用予約案内」を使えば学校名義で事前予約でき無料。一般申込みは抽選になり希望日を取れないおそれがあるため、必ず学校経由のルートを使う。8月末までに開催日を確定させる（後工程すべての起点になるため）。

「予約（仮予約）」と「利用許可申請書の提出（本申請）」は別の手続き。仮予約だけで安心して申請を忘れないよう注意（2025年度は申請が翌年2月までずれ込み、直前に気づいて慌てて提出した実例あり）。詳しい注意点は7章付録を参照。

B
保護者説明会・協賛広告依頼の開始時期：10月末〜11月上旬

やること

  • ミニ演奏会＆保護者説明会の準備・開催
  • 協賛広告の訪問先・担当者の割り振り

誰に確認するか

  • 顧問 → 説明会の日程、資料の大量印刷依頼
  • 保護者全体 → 説明会参加の呼びかけ（家族・知人の鑑賞可否も含め案内）

会場は音楽室前多目的広場＆第2音楽室が前例。開催日は年度により土曜／日曜が変動する（2024年度：10/26(土)、2025年度：11/2(日)）。2・3年生は前年と同じ訪問先に割り振ると引き継ぎがスムーズ。

当日の台本・配布資料・進行の詳細は、別紙「ミニ演奏会＆保護者説明会 開催準備マニュアル」を参照。

C
協賛広告・協賛金の収集時期：説明会当日〜1月下旬

やること

  • 役員会から保護者会全体へ、協賛広告・寄付金依頼への協力を呼びかける
  • 趣意書・広告依頼一式の配布
  • 各保護者による協賛事業者への訪問・依頼（①訪問→②説明・書類預け→③先方へ確認→④担当保護者が協賛金を受取り→⑤デザイン確認、の順で進める）
  • 広告デザイン・サイズの確定
  • 担当保護者が受領した協賛金を役員会（会計）へ引き渡し、リストを更新
  • 請求書・領収書の発行

誰に確認するか

  • 協賛事業者 → デザイン内容、金額確定、支払いタイミングの希望（各保護者経由）
  • 担当保護者 → 受領済みの協賛金額、事業者情報
  • 会計 → 入金確認、領収書発行、振込希望時の口座案内・請求書対応

企業・個人への直接の依頼と協賛金の一次受領は各保護者が行う。役員会は「保護者会全体への呼びかけ」と「担当保護者から役員会への協賛金集約」を担う。広告協賛リストで事業者ごとに「アクション中→確約→担当者受領→役員会受領→デザイン決定→完了」のステータスを管理する。

依頼締切は12月中旬目安（2025年度実績：12/14。状況により延長可）。デザイン確認結果の報告締切は1月中旬目安（2025年度実績：1/11）、デザインの最終確定は1月末目安（2025年度実績：1/30。以降の変更は原則不可）。パンフレット制作の進行があるため期日厳守。

重複依頼を避けるため、担当が決まっていない事業者へは「依頼を受けていますか」と一声かける／寄付は5,000円単位・「寄付金」名目の領収書希望にも対応する等、実務上の注意点は「ミニ演奏会＆保護者説明会 開催準備マニュアル」3章⑧に詳細あり。

6

振り返り・申し送り事項

良かった点（継続推奨）

  • 経験者保護者を役員グループへ招く（人数は多すぎない範囲で）
  • イベント「お知らせ」の様式化で会長の負担軽減
  • 11〜12月の保護者向けミニ演奏会を継続開催
  • 「生徒主体」を徹底し、保護者会はサポートに徹する
  • 生徒送迎は各保護者への個別依頼方式にして取りまとめ負担を軽減
  • イベントごとに担当を具体的に割り振る（撮影係・キーパー係等）
  • 協力金は年度内に生徒へ還元
  • 公民館予約は学校経由の事前予約枠を利用（11月案内を見逃さない）

改善したい点

  • 役員内の業務分担が不十分になりがち → 各自が主体的に確認し合う体制を作る
  • 会長に顧問対応・保護者対応が集中しがち → 他役員が意識的にフォロー
  • 意思決定は会長が抱え込まず役員会に諮る（会長以外にファシリテーター役も）
  • 会計業務（やりとり・資料整理）の負担が大きい → フォロー体制を作る
  • 資料整理が手薄になりがち → 簡単なマニュアル整備を継続する（本資料もその一環）
  • Googleドライブ等の共有範囲は個人情報保護の観点から必要最小限にする

※上記は「前回の対応」であり唯一の正解ではありません。年度により顧問や状況が変わるため、参考情報としてご活用ください。

付録

主な外部業者前例・年度により変動あり
  • パンフレット印刷：新栄印刷さま
  • DVD撮影／制作：チャンネル１さま（那覇市字小禄）
  • 楽器購入：クラフト楽器
会場予約に関する重要事項 
  • 一般受付は3月第一営業日だが、学校名義なら11月案内で事前予約可・無料
  • 抽選を避けるため必ず学校経由のルートを使う
  • 「予約（仮予約）」と「利用許可申請書の提出（本申請）」は別の手続き。仮予約だけで満足して申請を忘れがち（2025年度は申請が翌年2月までずれ込んだ実例あり）。役員引継ぎ資料に両方を明記し、担当者が変わっても引き継がれるようにする
  • ホール利用申請と駐車場利用申請は窓口・書類が別（駐車場は公民館とは別の建物にあることが多く、生涯学習振興課で場所を確認できる）
  • 「公民館使用料減免申請書」の提出を忘れると使用料が発生する場合がある。学校名義利用は本来無料のため、減免申請書の提出漏れに注意
  • 減免申請書には顧問の押印が必要な場合がある（学校印は不要なことが多いが窓口担当者により対応が異なるため要確認。「前年は押印なしで受領された」実績を伝えると通ることがある）
  • 「公民館使用日時」の原本は公民館窓口で直接受け取る必要があり、コピーでは代用できない
  • 申請書の「担当者」欄と実際の提出者が異なる場合は、事前に窓口へ確認する
  • 本番当日の会場予約とは別に、ホール練習（リハーサル）日の予約も必要。引継ぎ資料から漏れやすいため必ず明記しておく。予約は1年前から可能な場合があるため早めに動く
  • 希望日程が他行事（市内大会等）と重なり取れないことがある。その場合は「リハーサルなし・当日搬入」「1日開催」「開演時刻を遅らせて駐車場の回転を図る」などの代替案を役員会・顧問で検討する
  • 駐車場が少ない年は、来場者への乗り合わせ案内など事前の周知を検討する
  • 予約・申請の受付時期（本番の半年前目安 等）や次年度・翌々年度分の予約が並行して動くため、「いつ・誰が・何を（仮予約／本申請）したか」を都度記録し、役員間で時系列を共有する
